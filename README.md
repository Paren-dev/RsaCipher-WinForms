# RsaCipher-WinForms

Десктопное приложение на **C# (Windows Forms)**, реализующее алгоритм асимметричного шифрования **RSA** полностью с нуля — без использования встроенных криптографических библиотек (`System.Security.Cryptography`).

Проект создан для отработки алгоритмов теории чисел, модульной арифметики и работы с файловым вводом-выводом в .NET.

## Возможности

* **Генерация ключевой пары ($e$, $d$, $n$):** автоматический подбор случайных простых чисел $p$ и $q$, расчёт модуля $n = p \cdot q$, функции Эйлера $\varphi(n)$ и вычисление открытого и закрытого ключей.
* **Шифрование и дешифрование текста:** побайтовая обработка строк с поддержкой кириллицы (кодировка `Windows-1251`).
* **Работа с файлами:** загрузка исходного/зашифрованного текста из `.txt` и сохранение результатов на диск через стандартные диалоговые окна Windows.

## Алгоритмическая реализация

Вся математическая база написана вручную:

1. **Быстрое возведение в степень по модулю (`ModPow`)** — рекурсивный алгоритм вычисления $m^e \bmod n$ за логарифмическое время $O(\log e)$ с защитой от переполнения через промежуточный `ulong`.
2. **Тест простоты Ферма (`IsPrimeFermat`)** — вероятностная проверка кандидатов в простые числа на базе 20 случайных оснований.
3. **Алгоритм Евклида (`Gcd`)** — поиск наибольшего общего делителя для выбора открытой экспоненты $e$, взаимно простой с $\varphi(n)$.
4. **Расширенный алгоритм Евклида (`ExtendedEuclidean`)** — нахождение модульного обратного элемента для вычисления закрытого ключа $d$.
